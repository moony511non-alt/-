# الأكس - أبو تيم v1.0

تطبيق للتبليغ الجماعي على إنستغرام

## ✨ المميزات
- إضافة 5 حسابات وهمية
- تبليغ جماعي عن حسابات مستهدفة
- واجهة عربية بسيطة
- حفظ واسترجاع الجلسات

## 📱 طريقة الاستخدام
1. شغل التطبيق
2. أضف حساباتك الوهمية
3. أضف الحسابات المستهدفة
4. اختر نوع البلاغ
5. اضغط "بدء التبليغ"

## ⚙️ المتطلبات
- Python 3
- مكتبة requests
